Memory Quick Mount (MQM)
=================================
一鍵掛載你的「記憶封存種子」，並可持續寫入代理的狀態快照，最後支援 rehydrate 還原。

準備：
1) 將你的種子檔放到本機，或維持預設 /mnt/data/20250806記憶封存小種子.json
2) 複製 config.sample.yaml → config.yaml，視需要調整 seeds/ 路徑。

用法：
# 掛載（讀取 seeds → 生成 context/mounted_context.json）
python3 memory_quick_mount.py --config config.yaml mount

# 記憶快照（事件驅動），例如來自 Genie3 的狀態：
python3 memory_quick_mount.py --config config.yaml snapshot \
  --agent Genie3 --state '{"scene_id":"level-1","tick":1,"objects":[{"id":"painting","pos":[3,0,1]}]}'

# 還原（合併已掛載的 context + 最後一筆快照）
python3 memory_quick_mount.py --config config.yaml rehydrate

輸出：
- context/mounted_context.json   # 彙整所有 seed 的索引
- snapshots/snapshots.jsonl      # 逐筆追加的狀態快照
- context/rehydrated.json        # 將已掛載的 context 與最後一筆快照合併

擴充：
- adapters/genie3_adapter.py     # 將 Genie3 事件轉為 snapshot 所需的 state 結構
- 可在 memory_quick_mount.py 中插入 AdvancedParticleCompressor 用於粒子化壓縮封存。
